## Nederlands

Eerste publieke release van **8star-prep (Noodvoorraad)**: een gratis, zelf te hosten web-app voor je noodvoorraad thuis.

- **Dashboard** met dagen eten en drinkwater voor je doelduur, totaaldekking en tekorten.
- **Voorraad** met partijen, locaties, THT/TGT-data en CSV-import en -export.
- **Voedingscatalogus** met 53 meegeleverde items (USDA SR28, altijd als schatting gemarkeerd).
- **Rantsoenplan** dag voor dag, alleen van wat je echt hebt, met exacte tekorten en een afdrukbare versie.
- **Houdbaarheid** met een dagelijkse e-mailsamenvatting via je eigen SMTP-server.
- Nederlands en Engels, geen telemetrie, geen accounts elders.

**Installeren:** maak in Dockhand een stack vanaf deze repository (`compose.yaml`, branch `main`) of draai `docker compose up -d --build`. Zie de [README](https://github.com/TimoM84/8star-prep#nederlands) voor de stappen en de verplichte `APP_ENCRYPTION_KEY`.

## English

First public release of **8star-prep (Emergency Pantry)**: a free, self-hosted web app for household emergency supplies.

- **Dashboard** with days of food and drinking water for your target duration, overall coverage and shortages.
- **Inventory** with batches, locations, best-before/use-by dates and CSV import and export.
- **Nutrition catalogue** with 53 bundled entries (USDA SR28, always marked as estimates).
- **Ration plan** day by day, using only what you actually have, with exact deficits and a printable version.
- **Expiry** overview and a daily email digest through your own SMTP server.
- Dutch and English, no telemetry, no third-party accounts.

**Install:** create a Dockhand stack from this repository (`compose.yaml`, branch `main`) or run `docker compose up -d --build`. See the [README](https://github.com/TimoM84/8star-prep#english) for the steps and the required `APP_ENCRYPTION_KEY`.
